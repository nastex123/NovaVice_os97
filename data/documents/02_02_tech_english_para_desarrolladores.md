# Nova Idiomas Colombia - Academia Oficial de Idiomas
## Curso de Tech English para Desarrolladores, TI y Científicos de Datos

### 1. Enfoque Especializado
Diseñado para ingenieros de software, analistas de QA, arquitectos cloud y product managers que trabajan en equipos distribuidos globales o empresas de tecnología en EE.UU. y Europa.

### 2. Módulos Temáticos
- Daily standups, sprint plannings y retrospectives en inglés fluido.
- Code reviews, documentación de arquitecturas en GitHub y creación de tickets Jira.
- Preparación integral para entrevistas técnicas y behavioral interviews con reclutadores de Silicon Valley.
